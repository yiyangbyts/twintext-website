安装与首次使用

四步开始阅读

  1. 下载 XPI，保留原后缀

    把上方安装包保存到本机，无需解压。安装前在 Zotero 的“关于”窗口确认当前版本符合本页范围。

  2. 从文件安装插件

    在 Zotero 中进入“工具 → 插件”，点击齿轮菜单，选择“从文件安装插件”，选中刚下载的 .xpi。根据提示完成安装并重启 Zotero。

  3. 配置授权与翻译服务

    打开 Zotero 设置中的 TwinText 页面，按已有授权信息完成激活。选择包含在授权中的官方翻译服务，或填写自己的 API URL、Key 与所需模型名；运行连接测试后保存。

  4. 打开 PDF，选择范围与排列

    在阅读器中打开 TwinText，先从当前页验证效果，再处理所需页范围或全文。调整原译文排列、字号和行距，最后按需要导出文件或笔记。

升级后建议重新开始目标页面的翻译任务，让新版本的解析与公式保护规则生效。保留原始 PDF 和既有资料，完成实际页面核对后再扩大使用范围。

下载与使用常见问题

以后会自动更新到最新版吗？

安装包已配置 TwinText 公共更新清单。新版本正式发布并写入该清单后，Zotero 的插件更新检查即可发现兼容版本；是否自动下载或安装由 Zotero 的更新设置决定。候选版不会自动推送给公开版用户。

插件授权和 API 费用是一回事吗？

两者分开。官方翻译服务取决于你的授权套餐及额度；接入第三方 API 时，由对应提供方管理可用性、用量与费用。本页不提供购买或支付流程。

是不是必须安装 Python？

标准解析和前端 PP-DocLayoutV2 WASM 方案不要求单独安装 Python。选择其他本地增强引擎时，按该引擎的运行环境要求配置；进阶解析功能以实际发行版本为准。

PDF 导出也是 1:1 译文页面吗？

研发版本的阅读器按原页面结构还原译文；PDF 导出把原文页面图像与按页重排的双语内容组合输出，两者形式不同。具体功能请核对公开版发行说明。

安装以后，所有翻译都会离线完成吗？

本地版面解析与翻译服务是两个环节。正文会发送给你选中的翻译服务；只有实际接入本地翻译服务并满足对应条件时，翻译环节才可能在本机完成。

为什么更新记录还有 1.0.39？

更新记录包含开发迭代和候选版，不代表均已公开发行。1.0.39 的历史验证记录在 测试范围页；公开下载与 Zotero 自动更新始终以 更新清单为准。
